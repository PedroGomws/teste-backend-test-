# Teste 3 — Carrinho de compras

**Função:** `calcular_total_carrinho(carrinho)`

Receba uma lista de itens (`preco` + `quantidade`) e retorne o valor total da compra. Carrinho vazio = `0.0`.

```python
carrinho = [
    {"item": "Teclado", "preco": 100.00, "quantidade": 2},
    {"item": "Mouse", "preco": 50.00, "quantidade": 1},
]
calcular_total_carrinho(carrinho)
# -> 250.00
```
