# Teste 4 — Limpeza de texto

**Função:** `padronizar_nomes(nomes)`

Receba nomes "sujos" (espaços extras, maiúsculas/minúsculas misturadas) e retorne-os formatados corretamente: sem espaços nas extremidades e com a capitalização adequada de nomes próprios.

```python
padronizar_nomes([" joão silva ", "MARIA SOUZA", "ana", "   pedro   "])
# -> ["João Silva", "Maria Souza", "Ana", "Pedro"]
```
