# Teste 2 — Filtragem de dados

**Função:** `filtrar_usuarios_ativos(usuarios)`

Receba uma lista de dicionários e retorne apenas os **nomes** dos usuários com `ativo=True`.

```python
usuarios = [
    {"nome": "Alice", "ativo": True},
    {"nome": "Bob", "ativo": False},
    {"nome": "Carlos", "ativo": True},
]
filtrar_usuarios_ativos(usuarios)
# -> ["Alice", "Carlos"]
```
